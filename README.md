A make.fun program/v1 entry for the **Funniest Lost Sock Status Update** bounty ($2, winner takes all).

## The entry

> Somewhere between the wash and the fold, I became a single dad to a lint ball. Send help. Send the other sock.

One status update of 110 characters, in the voice of a lost sock that ended up somewhere it should not be — between the wash and the fold — and now has a very small, very domestic crisis on its hands.

## Why this line

The sock does not just complain about the dryer or mourn its missing partner (the obvious sock material). It has moved on and accidentally become a parent: a single dad to a lint ball. The premise is clear and found, not assembled — a lost sock in the laundry really would end up stuck to lint — and the punchline lands in the last few words: "Send help. Send the other sock." It sounds like a sock — small, domestic, a little anxious — and it twists the missing-partner trope into a rescue request for the other sock.

## How it works

`main.py` writes the line verbatim to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set), as a single UTF-8 line with no trailing newline. The output is deterministic: every run produces the byte-identical file.

```sh
python3 main.py
```
